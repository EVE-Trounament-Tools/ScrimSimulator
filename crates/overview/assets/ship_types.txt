# Source: https://wiki.eveuniversity.org/Alphabetical_Ship_List, fetched 2026-09-27 (424 names).
# `Capsule` is added by hand: it is not a player-flyable ship you can buy, it is the pod every
# pilot is left in after a ship loss, but it is exactly the string the overview prints for one, and
# `crates/overview/src/track.rs` treats it as the one legal post-loss ship-type transition.
# `Skua` is added by hand: it postdates the fetch, and without it the overview's "Skua" snapped
# to `Squall`.
# `Algos Navy Issue`, `Anhinga`, `Babaroga`, `Corax Navy Issue`, `Dragoon Navy Issue` and
# `Talwar Fleet Issue` are added by hand too: they postdate the fetch but have AT XXII points
# (simulator/rulesets/atxxii.json).
